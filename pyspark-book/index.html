Window functions: anatomy, frames and the default-frame trap

A window = partition (which rows belong together) + order (sequence inside the group) + frame (which rows around the current one an aggregate sees). Rows are not collapsed, unlike groupBy.

40 rapid-fire PySpark coding-round questions

Short verbal questions that come up between coding tasks. Answer each in one or two sentences.

1. What is lazy evaluation and why does it matter in a coding round?

Transformations build a plan; nothing runs until an action (show, count, write, collect). Spark can then optimise the whole chain (pushdown, pruning). It also means an error in a transformation may only appear at the action.

2. Narrow vs wide transformations?

Narrow (select, filter, withColumn) work within a partition; wide (groupBy, join, distinct, window, orderBy) need a shuffle. Count the shuffles in your answer.

3. Why avoid collect()?

It brings all rows to the driver, which can run out of memory. Use show, take, limit, or write the result.

4. cache() vs persist()?

cache = persist(MEMORY_AND_DISK) for DataFrames. Cache only when reused by several actions, after filtering, and unpersist when done.

5. repartition vs coalesce?

repartition(n or cols) shuffles to exactly n partitions, can increase; coalesce(n) merges without a full shuffle, only decreases, can create uneven partitions.

6. count(*) vs count(col)?

count(*) counts rows; count(col) skips NULLs. Use it to count matches after a left join.

7. distinct vs dropDuplicates?

distinct compares all columns; dropDuplicates(subset) keeps one arbitrary row per subset key.

8. Why is a Python UDF slow?

Rows are serialised to Python workers and back, and Catalyst can't optimise inside it. Prefer built-ins; then pandas UDFs.

9. How do you handle NULLs in joins?

NULL keys never match with =; use eqNullSafe/<=> or replace with a sentinel when NULL is meaningful.

10. What does explode do with an empty array?

Emits no rows, so the parent row disappears; use explode_outer to keep it.

11. row_number vs rank vs dense_rank?

Unique numbers; ties share a rank with gaps; ties share a rank without gaps.

12. Why does last() over an ordered window return the current row?

The default frame ends at the current row; specify rowsBetween(unboundedPreceding, unboundedFollowing).

13. How do you do a running total?

sum over a window partitioned and ordered, with rowsBetween(unboundedPreceding, currentRow).

14. How do you find rows in A not in B?

left_anti join (or NOT EXISTS). Avoid NOT IN with nullable subqueries.

15. Broadcast join: when and how?

When one side is small; automatic under spark.sql.autoBroadcastJoinThreshold (10 MB) or F.broadcast(df). Check BroadcastHashJoin in the plan.

16. What is skew and how do you fix it?

Some keys have far more rows, so one task runs long. Fixes: broadcast, AQE skew join, salting, filtering hot keys separately.

17. groupByKey vs reduceByKey?

reduceByKey combines values within each partition before shuffling; groupByKey ships all values and builds lists in memory.

18. How do you deduplicate keeping the latest record?

row_number over the key ordered by timestamp desc (plus tie-breaker), keep 1.

19. What's the difference between where and filter?

None; aliases.

20. How do you pivot efficiently?

groupBy().pivot(col, [values]).agg(): pass the values so Spark skips a distinct pass.

21. How do you write one file per partition value?

repartition by the partition column before write.partitionBy; cap size with maxRecordsPerFile.

22. How do you read only what's new?

Partition filters on a date, a watermark column, Glue job bookmarks, or Iceberg snapshot-range reads.

23. How do you parse JSON strings?

from_json with an explicit schema; get_json_object for a few fields; schema_of_json to derive a schema.

24. How do you test PySpark code?

Pure functions DataFrame → DataFrame, pytest with a session fixture, assertDataFrameEqual (3.5) on small inputs.

25. What does AQE do?

Re-optimises at runtime using shuffle statistics: coalesces small partitions, switches to broadcast, splits skewed partitions.

26. Why do you get 'Column is ambiguous' after a join?

Both sides have the column; alias the DataFrames or join on a list of names.

27. How do you add a sequential ID?

monotonically_increasing_id() is unique but not consecutive; row_number over an order gives consecutive IDs but needs a global sort (one partition if no partitionBy).

28. How to compute a median?

percentile_approx (fast) or median/percentile (3.4+, exact).

29. What is a date spine?

A generated sequence of dates (sequence + explode) used to fill missing periods with a left join.

30. How do you compare two DataFrames for differences?

exceptAll both ways for row-level differences, or full outer join on keys with null-safe column comparison or hashes.

31. What does exceptAll do vs subtract?

exceptAll keeps duplicates (multiset difference); subtract/except is set difference (removes duplicates).

32. When does a window cause an OOM?

When a single partition key has huge numbers of rows (skew), or no partitionBy at all; all rows of a partition are processed by one task.

33. How do you handle late-arriving data in batch?

Reprocess a lookback window of partitions, with an idempotent write (overwrite partitions or MERGE).

34. What's idempotent writing?

Re-running gives the same result: dynamic partition overwrite, MERGE by key, or Iceberg commits; never blind append for retried batches.

35. How do you handle schema evolution when reading?

mergeSchema for Parquet (costly), or explicit schemas; with Iceberg, ALTER TABLE ADD COLUMN and schema evolution on write.

36. Why can a filter after a UDF not be pushed down?

Spark can't reason about the UDF's output, so the filter can't move below it to the scan.

37. How do you read only certain columns from Parquet?

Select them early; column pruning and projection pushdown read only those columns (check ReadSchema).

38. What is the difference between select and withColumn?

select defines the full output column list; withColumn adds or replaces one column. Many withColumn calls in a loop bloat the plan.

39. How would you unit-test a function that uses current_date()?

Pass the run date as a parameter (or literal column) so tests are deterministic.

40. Coalesce function vs coalesce() partitions?

F.coalesce returns the first non-NULL column value; DataFrame.coalesce(n) reduces partitions. Same name, unrelated.
