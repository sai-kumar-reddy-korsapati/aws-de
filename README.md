## Use it on your phone
Open the live site, then **Add to Home Screen** (Safari share menu, or Chrome's ⋮ menu).

## How it's hosted
Plain static HTML on GitHub Pages, served from the `main` branch root. No build step. Quiz progress is stored in each browser's local storage.

AWS account IDs in code samples are placeholders (`123456789012`).
